# Installation

ReactPilot is distributed as an NPM package. You can install it globally or use it via `npx`.

## Prerequisites

- **Node.js**: Version 18 or higher.
- **NPM**: Version 7 or higher.

## Global Installation

To install ReactPilot globally on your machine:

```bash
npm install -g @reactpilot/cli
```

Verify the installation:

```bash
reactpilot --version
```

## Using via npx

You can run ReactPilot commands without installing it globally:

```bash
npx @reactpilot/cli analyze .
```

## Uninstall

To remove ReactPilot from your system:

```bash
npm uninstall -g @reactpilot/cli
```
