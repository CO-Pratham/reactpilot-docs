# ReactPilot Pro & Managed AI

**ReactPilot Pro** provides managed AI capabilities, zero-setup API key infrastructure, and automated GitHub Pull Request review bots for teams.

## Features

- **⚡ Zero API Config:** Use managed AI models without acquiring or configuring OpenAI API keys.
- **🤖 Automated GitHub PR Review Bot:** Automatically posts AST and AI review comments on team Pull Requests.
- **🔒 Enterprise Security:** Multi-repo centralized code quality metrics and custom AST rules.
- **🎁 14-Day Free Trial:** Try Pro features with no credit card required.

## Joining the Waitlist

Launch the Developer Center dashboard (`reactpilot dashboard`) and click **"Join Pro Waitlist"**, or run:

```bash
reactpilot features
```

Follow the prompt link to submit your team size and feature requirements.
