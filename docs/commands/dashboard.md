# `reactpilot dashboard`

Launch the local Developer Center web dashboard.

## Usage

```bash
reactpilot dashboard [options]
```

## Options

| Option | Description |
| :--- | :--- |
| `-p, --port <number>` | Port to run the dashboard server on (Default: `3000`) |

---

## Features

- **Dynamic Connection Status:** Monitors local agent and API key setup in real-time (`Agent & API Connected`).
- **Pro Waitlist Managed AI:** Request early access to managed zero-key AI and team GitHub PR review bots.
- **Visual Graphs & Chat:** Browse interactive architecture graphs and historical AI RAG chat sessions.
