# Generate Command

The `generate` command scaffolds new React components, hooks, or other artifacts using AI to ensure they follow best practices and your project's style.

## Usage

```bash
reactpilot generate <type> <name> [options]
```

- `<type>`: What to generate (e.g., `component`, `hook`, `test`).
- `<name>`: The name of the artifact (e.g., `Button`, `useFetch`).

## Examples

Generate a new component:

```bash
reactpilot generate component UserProfile
```

Generate a custom hook:

```bash
reactpilot generate hook useLocalStorage
```
