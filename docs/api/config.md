# Configuration

ReactPilot can be configured via a `reactpilot.config.js` file (planned) or environment variables.

## Environment Variables

| Variable | Description | Default |
| :--- | :--- | :--- |
| `REACTPILOT_API_KEY` | API Key for LLM provider | - |
| `REACTPILOT_API_BASE_URL` | Base URL for LLM API | `https://api.openai.com/v1` |
| `REACTPILOT_MODEL` | Model name to use | `gpt-4` |
